# Версии

У Эфира три вещи с отдельными версиями: приложение, Bot API и библиотеки для ботов.
Меняются они независимо.

## Приложение: `X.Y.Z`

Номер вида `0.5.5` — версия приложения для Windows (оболочки: окно, обновления, оверлей,
определение игр). Интерфейс чата приходит с сервера и обновляется без новой версии
приложения.

| Часть | Когда растёт | Как приходит |
| --- | --- | --- |
| `Z` — патч | исправления и небольшие возможности в оболочке | обновлением внутри приложения: скачивается и ставится при перезапуске, без установщика |
| `Y` — минорная | новая версия Electron, заметные изменения, изменения, после которых нельзя откатиться на прошлую версию без установщика | обновлением через установщик, тоже без вопросов и окон |
| `X` — мажорная | `0` — пока Эфир в активной разработке; `1.0` выйдет, когда приложение и протокол устоятся | — |

- Откатиться из настроек («Обновления») можно на версии с тем же Electron; на остальные —
  установщиком из [релизов](../../../releases).
- Обновления подписаны: приложение ставит только то, что подписано ключом разработчика.
- Пока `X` равно `0`, протокол между приложением и сервером может меняться в любой версии.
  Сервер и приложение обновляются вместе, так что пользователей это не касается.

## Bot API: `v1`

Версия в адресе: `/api/v1/…`. Внутри `v1`:

- поля в ответах, события, запросы и необязательные параметры только **добавляются**;
- существующие поля не меняют тип и смысл и не исчезают;
- новые ограничения (лимиты, длины) могут появиться, только если без них сервер нельзя
  защитить; они попадут в [историю изменений](bots/changelog.md) в тот же день.

Несовместимые изменения выйдут как `v2` по новым адресам (`/api/v2/…`), а `v1` проработает
рядом не меньше трёх месяцев. Об этом будет написано в истории изменений и в релизе
заранее.

Чего `v1` не обещает: порядок полей в JSON, тексты ошибок (опирайтесь на статус), и что в
ответе нет полей сверх описанных.

## Библиотеки `efir-bot`: семантическое версионирование

Библиотеки для Node.js (npm) и Python (PyPI) нумеруются по [SemVer](https://semver.org/lang/ru/):

| Часть | Когда растёт |
| --- | --- |
| мажорная | код бота придётся поменять: убран или переименован метод, событие, параметр |
| минорная | новые методы, события, параметры; старый код работает как раньше |
| патч | исправления без изменений в том, как библиотекой пользоваться |

Версии библиотек не связаны с версией приложения: `efir-bot 1.x` работает с Bot API `v1`.

## Релизы

У каждого релиза одинаковое описание:

- **Добавлено** — новые возможности;
- **Изменено** — что работает иначе;
- **Исправлено** — ошибки;
- **Безопасность** — всё, что связано с защитой;
- **Известные проблемы** — что ещё не так и как это обойти;
- **SHA-256** — контрольная сумма установщика.

Пустые разделы не пишутся.
