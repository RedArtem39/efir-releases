# Ошибки

Ошибка — HTTP-статус и `{ "error": "текст" }`. Текст понятен человеку: его можно показать
как есть. Опираться в коде лучше на статус, а текст — для людей и журналов. У `429` есть ещё
`retry_after` (секунды) и заголовок `Retry-After`.

## Статусы

| Статус | Когда | Что делать |
| --- | --- | --- |
| `400` | неверные данные: пустой текст, слишком длинное имя, неизвестный id в теле | исправить запрос; текст ошибки скажет, что именно |
| `401` | токен неверный или сброшен через `/token` | взять новый токен у `@bot_bot` |
| `403` | не хватает прав, бот не на сервере, личка закрыта | дать боту роль с нужным правом или проверить права заранее |
| `404` | нет такого сообщения, канала, сервера, роли, файла | id устарел или бот не видит этот объект |
| `405` | метод не поддерживается этим адресом | проверить метод по [справочнику](rest.md) |
| `413` | файл или тело запроса слишком большие | файлы — до 1 ГБ, картинки — до 20 МБ, аватар — до 8 МБ, JSON — до 24 000 байт |
| `415` | формат не поддерживается или тело не JSON | передать `Content-Type: application/json`, у аватара — картинку или видео |
| `416` | неверный заголовок `Range` при скачивании | исправить диапазон |
| `429` | лимит | подождать `retry_after` секунд и повторить |
| `507` | хранилище сервера заполнено | написать владельцу сервера |

## Тексты по темам

### Доступ

| Статус | Текст | Причина |
| --- | --- | --- |
| 401 | Неверный токен бота | токен с ошибкой или сброшен |
| 403 | Боты работают только через /api/v1 | запрос не к `/api/v1/…` |
| 403 | Недоступно для ботов | этот адрес — только для людей |
| 403 | Вы не участник этого сервера | бот не на сервере |
| 403 | Недостаточно прав | нет нужного права на сервере или в канале |
| 403 | Нет доступа к этому каналу | бот не видит канал |
| 403 | Нет доступа | бот не видит канал, где лежит файл |
| 403 | Вы заблокированы на этом сервере | бот забанен |

### Запрос

| Статус | Текст | Причина |
| --- | --- | --- |
| 405 | Метод не поддерживается | не тот HTTP-метод |
| 415 | Ожидается JSON | нет `Content-Type: application/json` |
| 413 | Слишком большой запрос | JSON больше 24 000 байт |
| 400 | Некорректный JSON | тело — не JSON |
| 400 | Некорректный запрос | тело — JSON, но не объект |
| 400 | Название: от 1 до N символов, Имя: …, Сообщение: … | пустое или слишком длинное поле; N — максимум |

### Сообщения

| Статус | Текст | Причина |
| --- | --- | --- |
| 429 | Слишком много запросов | больше 50 запросов в секунду от бота |
| 403 | Нельзя писать в этом канале | нет права «Отправлять сообщения» или это не текстовый канал |
| 429 | Слишком часто. Подождите немного | больше 5 сообщений за 5 секунд в канал или 20 пересылок за 10 секунд |
| 429 | Медленный режим: подождите N с | в канале включён медленный режим |
| 403 | Нельзя прикреплять файлы в этом канале | нет права «Прикреплять файлы» |
| 400 | Вложение не найдено | id файла не загружен этим ботом в этот канал или уже в другом сообщении |
| 400 | Сообщение для ответа не найдено | `reply_to` — из другого канала или удалено |
| 404 | Сообщение не найдено | нет такого сообщения или бот его не видит |
| 403 | Изменить можно только своё сообщение | правка чужого |
| 403 | Можно удалить только своё сообщение | удаление чужого без «Управлять сообщениями» |
| 403 | Нельзя ставить реакции в этом канале | нет права «Добавлять реакции» |
| 400 | Неизвестная реакция | в адресе не один эмодзи |
| 400 | Закрепить можно не больше 50 сообщений | в канале уже 50 закрепов |
| 400 | В этом канале нет сообщений | закреп в пустом канале |
| 403 | Вы заблокировали этого пользователя | бот сам заблокировал человека |
| 403 | Сообщение не доставлено: пользователь ограничил, кто может ему писать | человек закрыл личку |

### Пересылка

| Статус | Текст | Причина |
| --- | --- | --- |
| 400 | Выберите от 1 до 10 чатов | `channel_ids` пустой или длиннее 10 |
| 400 | Сюда нельзя переслать | чат — не текстовый канал и не личка |
| 403 | В этот канал нельзя прикреплять файлы | у сообщения есть вложения, а в чате нет права «Прикреплять файлы» |

### Файлы

| Статус | Текст | Причина |
| --- | --- | --- |
| 400 | Пустой файл | тело загрузки пустое |
| 413 | Файл больше 1 ГБ, Картинка больше 20 МБ, Файл больше 8 МБ | превышен размер; 8 МБ — у аватара |
| 400 | Голосовые и видеосообщения записываются в WebM | `variant` у файла не WebM |
| 404 | Файл не найден | нет файла, он удалён или ещё не в сообщении |
| 416 | Диапазон вне файла | `Range` за концом файла |
| 507 | Хранилище сервера заполнено | закончилось место, отведённое под файлы |
| 507 | На диске сервера заканчивается место | на диске осталось меньше 5 ГБ |

### Серверы и приглашения

| Статус | Текст | Причина |
| --- | --- | --- |
| 404 | Сервер не найден | нет сервера или бот не на нём |

| 404 | Приглашение не найдено | удаление несуществующего приглашения |
