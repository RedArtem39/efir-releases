# Объекты и права

Общее для всех объектов:

- id — строки. Время — миллисекунды с 1970 года.
- Тип `строка?` — строка или `null`.
- Сервер может добавлять новые поля: не полагайтесь на то, что их нет. Существующие поля
  не меняют смысл внутри версии `v1`.
- Внутри API сервер местами называется `space` (`space_id`), в документации — сервер.

## Пользователь

```json
{
  "id": "000000002",
  "username": "Helper_bot",
  "name": "Помощник",
  "bio": "",
  "color": "sage",
  "bot": true,
  "verified": false,
  "avatar_media": { "url": "/avatars/….png", "kind": "image", "crop": null },
  "cosmetics": {},
  "created": 1790322464037
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | числовой id, дополненный нулями до 9 знаков |
| `username` | строка | уникальный, без учёта регистра; регистр при показе сохраняется |
| `name` | строка | отображаемое имя, до 32 символов |
| `bio` | строка | «Обо мне», до 190 символов |
| `color` | строка | цвет аватара без картинки |
| `bot` | логическое | это бот |
| `verified` | логическое | галочка от владельца платформы |
| `avatar_media` | объект? | `{ url, kind: "image" \| "video", crop }`, `url` — от корня сервера; `null` без аватара |
| `cosmetics` | объект | оформление профиля (рамка, эффект и т. п.), если выбрано |
| `created` | число | время регистрации |
| `owner` | логическое | есть только у владельца платформы, `true` |

## Участник

Пользователь на сервере (в `members` [сервера](#сервер)): поля пользователя и ещё

| Поле | Тип | Описание |
| --- | --- | --- |
| `roles` | массив строк | id ролей участника, без `@everyone` |
| `online` | логическое | в сети |
| `status` | строка | `online`, `idle`, `dnd` или `offline` |
| `activity` | объект? | «Играет в …»: `{ name, since }`; `null`, если ничего |

## Сервер

```json
{
  "id": "93d161f9-…",
  "name": "Кенты",
  "description": "",
  "owner_id": "000000001",
  "public": false,
  "verified": false,
  "created": 1790322464041,
  "permissions": 3247681,
  "top": 1,
  "owned": false,
  "roles": [],
  "channels": [],
  "members": [],
  "voice_states": []
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | |
| `name` | строка | до 40 символов |
| `description` | строка | до 300 символов |
| `owner_id` | строка | владелец |
| `public` | логическое | виден в поиске серверов, вступить можно без приглашения |
| `verified` | логическое | галочка от владельца платформы |
| `created` | число | |
| `permissions` | число | права бота на сервере: сумма его ролей |
| `top` | число | позиция высшей роли бота |
| `owned` | логическое | бот — владелец |
| `roles` | массив | [роли](#роль), от высшей |
| `channels` | массив | [каналы](#канал) в порядке показа |
| `members` | массив | [участники](#участник) |
| `voice_states` | массив | [голосовые состояния](#голосовое-состояние): кто сейчас в голосовых каналах |

## Канал

```json
{
  "id": "308bc030-…",
  "space_id": "93d161f9-…",
  "name": "общий",
  "kind": "text",
  "topic": "",
  "parent_id": "74a9c3e5-…",
  "position": 0,
  "slowmode": 0,
  "synced": true,
  "bitrate": 64,
  "user_limit": 0,
  "overwrites": [{ "type": "role", "id": "93d161f9-…", "allow": 0, "deny": 2048 }],
  "permissions": 3247681
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | |
| `space_id` | строка? | сервер канала; у личного чата — `null` |
| `name` | строка | до 32 символов |
| `kind` | строка | `text`, `voice`, `category`; личный чат — `dm` |
| `topic` | строка | тема текстового канала, до 1024 символов |
| `parent_id` | строка? | категория или `null` |
| `position` | число | порядок внутри категории |
| `slowmode` | число | секунды между сообщениями одного участника, 0 — выключено |
| `synced` | логическое | особые права берутся у категории |
| `bitrate` | число | голосовой: кбит/с, 8–96 |
| `user_limit` | число | голосовой: 0 — до 25 человек |
| `overwrites` | массив | особые права: `{ type: "role" \| "member", id, allow, deny }` |
| `permissions` | число | итоговые права бота в этом канале |

## Роль

```json
{
  "id": "7a0fd5d2-…",
  "space_id": "93d161f9-…",
  "name": "Модератор",
  "color": "#e91e63",
  "hoist": true,
  "permissions": 8198,
  "position": 2,
  "everyone": false,
  "created": 1790322464055
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | у `@everyone` равен id сервера |
| `space_id` | строка | |
| `name` | строка | до 32 символов |
| `color` | строка? | `#rrggbb` или `null` |
| `hoist` | логическое | показывать отдельной группой в списке участников |
| `permissions` | число | [биты прав](#права) |
| `position` | число | чем больше, тем выше; у `@everyone` — 0 |
| `everyone` | логическое | это `@everyone` |
| `created` | число | |

## Сообщение

```json
{
  "id": "cc41214d-…",
  "channel_id": "308bc030-…",
  "user_id": "000000001",
  "username": "Red_Artem39",
  "name": "Артём",
  "bot": false,
  "verified": false,
  "text": "привет",
  "created": 1790322464077,
  "edited": null,
  "pinned": null,
  "reply_to": null,
  "reply": null,
  "forward": null,
  "attachments": [],
  "embeds": [],
  "reactions": [{ "emoji": "👍", "count": 2, "mine": 0 }],
  "event": null,
  "poll": null
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | |
| `channel_id` | строка | |
| `user_id`, `username`, `name` | строки | автор |
| `bot`, `verified` | логические | автор — бот; у автора галочка |
| `text` | строка | до 4000 символов, [разметка](rest.md#разметка); пустая строка — только вложения |
| `created` | число | |
| `edited` | число? | время последней правки |
| `pinned` | число? | время закрепления |
| `reply_to` | строка? | id сообщения, на которое это ответ |
| `reply` | объект? | то сообщение: `{ id, channel_id, created, user_id, name, username, text, files }`, первые 200 символов текста; `{ id, deleted: true }`, если его удалили |
| `forward` | объект? | откуда переслано: `{ message_id, created, user, server?, channel? }`; у пересланного события или опроса внутри `event` или `poll` |
| `attachments` | массив | [вложения](#вложение) |
| `embeds` | массив | превью ссылок: `{ url, type: "link" \| "image", site, title, description, color, image, large }` |
| `reactions` | массив | `{ emoji, count, mine }`; `mine` — 1, если реакцию поставил сам бот |
| `event` | объект? | [событие](#событие) в этом сообщении |
| `poll` | объект? | [опрос](#опрос) в этом сообщении |

В событиях шлюза сообщение приходит вместе с `server_id` (или `null` в личке) и `dm`.
В библиотеках `reply` и `forward` называются `repliedTo` / `replied_to` и `forwardedFrom` /
`forwarded_from`, чтобы не путаться с методами `reply()` и `forward()`.

## Вложение

```json
{
  "id": "b6129711-…",
  "name": "report.pdf",
  "mime": "application/pdf",
  "kind": "file",
  "size": 48213,
  "width": null,
  "height": null,
  "url": "/attachments/b6129711-…/report.pdf",
  "expired": false
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | |
| `name` | строка | до 120 символов |
| `mime` | строка | тип по содержимому |
| `kind` | строка | `image`, `video`, `audio` или `file` |
| `size` | число | байты |
| `width`, `height` | число? | размер картинки или видео, если его передали при загрузке |
| `url` | строка? | от корня сервера; `null`, если файл удалён |
| `expired` | логическое | файл удалён: его никто не открывал 30 дней |
| `spoiler` | `true` | картинка или видео под спойлером; поля нет, если не спойлер |
| `variant` | строка | голосовое сообщение (`voice`) или кружочек (`round`) из приложения; поля нет у обычных файлов |
| `duration` | число | длительность в секундах; поля нет у обычных файлов |
| `waveform` | строка | 64 байта громкости в base64; поля нет у всего, кроме `voice` |

## Голосовое состояние

```json
{
  "user_id": "000000001",
  "channel_id": "5b0c…",
  "self_mute": false,
  "self_deaf": false,
  "mute": false,
  "deaf": false,
  "speaking": false,
  "streaming": false,
  "stream_audio": false,
  "stream_quality": null,
  "stream_viewers": 0
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `user_id`, `channel_id` | строки | кто и в каком голосовом канале |
| `self_mute`, `self_deaf` | логические | выключил микрофон или звук сам |
| `mute`, `deaf` | логические | выключено модератором |
| `speaking` | логическое | говорит прямо сейчас |
| `streaming` | логическое | показывает экран |
| `stream_audio` | логическое | трансляция со звуком |
| `stream_quality` | строка? | качество трансляции |
| `stream_viewers` | число | сколько смотрят трансляцию |

```json
  "message_id": "50d5d92f-…",
  "channel_id": "308bc030-…",
  "server_id": "93d161f9-…",

  "voice_channel": { "id": "…", "name": "Общий" },
  "going": 3,
  "attendees": [],
  "mine": "going"

```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id`, `message_id`, `channel_id`, `server_id`, `creator_id` | строки | |
| `title` | строка | до 100 символов |
| `description` | строка | до 1000 символов |
| `starts` | число | время начала |
| `voice_channel` | объект? | `{ id, name }` — где собираются |

| `attendees` | массив | первые 8 идущих, [пользователи](#пользователь) |
| `mine` | строка? | ответ бота: `going`, `not_going` или `null` |

## Опрос

```json
{
  "id": "11811ca9-…",
  "message_id": "8e47adb8-…",
  "question": "Во что играем?",
  "multiple": false,
  "closed": false,
  "voters": 4,
  "options": [{ "text": "CS2", "votes": 3 }, { "text": "Dota 2", "votes": 1 }],
  "mine": [0],
  "can_close": true
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id`, `message_id` | строки | |
| `question` | строка | до 300 символов |
| `multiple` | логическое | можно выбрать несколько вариантов |
| `closed` | логическое | опрос завершён |
| `voters` | число | сколько человек проголосовало |
| `options` | массив | `{ text, votes }`, 2–10 вариантов; индекс в массиве — номер для голосования |
| `mine` | массив чисел | индексы, за которые голосовал бот |
| `can_close` | логическое | бот может завершить опрос |

## Журнал аудита

```json
{
  "id": "7c8005e9-…",
  "space_id": "93d161f9-…",
  "actor_id": "000000002",
  "actor": { "id": "000000002", "username": "Helper_bot" },
  "action": "SERVER_UPDATE",
  "target_type": "server",
  "target_id": "93d161f9-…",
  "changes": { "description": { "old": "", "new": "тест" } },
  "reason": null,
  "created": 1790322464063
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id`, `space_id` | строки | |
| `actor_id`, `actor` | строка, [пользователь](#пользователь) | кто сделал |
| `action` | строка | что сделано, например `SERVER_UPDATE`, `MEMBER_KICK`, `MEMBER_BAN_ADD`, `INVITE_CREATE` |
| `target_type`, `target_id` | строки | над чем: `server`, `channel`, `role`, `member`, `invite`, … |
| `target` | [пользователь](#пользователь) | есть, если цель — участник |
| `changes` | объект? | `{ поле: { old, new } }` |
| `reason` | строка? | причина, до 512 символов |
| `created` | число | |

## Права

Битовая маска. Биты те же, что в Discord, кроме событий и опросов: в Discord они выше
32-го бита, а здесь права помещаются в 31 бит.

| Бит | Значение | Право |
| --- | --- | --- |
| `1 << 0` | 1 | создавать приглашения |
| `1 << 1` | 2 | выгонять участников |
| `1 << 2` | 4 | банить участников |
| `1 << 3` | 8 | администратор — все права |
| `1 << 4` | 16 | управлять каналами |
| `1 << 5` | 32 | управлять сервером |
| `1 << 6` | 64 | добавлять реакции |
| `1 << 7` | 128 | просматривать журнал аудита |
| `1 << 9` | 512 | видео (демонстрация экрана) |
| `1 << 10` | 1024 | просматривать каналы |
| `1 << 11` | 2048 | отправлять сообщения |
| `1 << 13` | 8192 | управлять сообщениями |
| `1 << 15` | 32768 | прикреплять файлы |
| `1 << 16` | 65536 | читать историю сообщений |
| `1 << 20` | 1048576 | подключаться к голосовым |
| `1 << 21` | 2097152 | говорить |
| `1 << 22` | 4194304 | отключать микрофон участникам |
| `1 << 23` | 8388608 | отключать звук участникам |
| `1 << 24` | 16777216 | перемещать участников |
| `1 << 28` | 268435456 | управлять ролями |
| `1 << 29` | 536870912 | создавать события |
| `1 << 30` | 1073741824 | создавать опросы |

Итоговые права считаются как в Discord:

1. права `@everyone`;
2. плюс права всех ролей участника;
3. особые права канала: сначала для `@everyone`, потом для ролей участника (запреты, потом
   разрешения), потом для самого участника;
4. канал с `synced: true` берёт особые права своей категории;
5. владелец сервера и роль с правом «Администратор» могут всё.

Права в канале без «Просматривать каналы» не дают ничего: бот такой канал не видит.
