# Боты Эфира

Боты устроены как в Telegram: отдельный аккаунт с юзернеймом на `_bot`, которым
управляет ваш код. Интерфейса для ботов в приложении нет — всё через `@bot_bot` и API.

## Создать бота

Напишите в личку `@bot_bot` («Личные сообщения» → «Найти или начать беседу» → `@bot_bot`):

| Команда | Что делает |
| --- | --- |
| `/newbot` | создать бота: имя, потом юзернейм на `_bot`; в ответ придёт токен |
| `/mybots` | список ваших ботов |
| `/token @имя_bot` | новый токен; старый сразу перестаёт работать |
| `/setname @имя_bot` | сменить имя |
| `/deletebot @имя_bot` | удалить бота (нужна фраза-подтверждение) |
| `/cancel` | отменить текущую команду |

Юзернейм: 5–32 символа, латинские буквы, цифры и `_`, начинается с буквы и
заканчивается на `_bot`. Регистр сохраняется (`@Tetris_bot`), а уникальность
проверяется без учёта регистра.

Токен — это пароль бота. Не выкладывайте его в код, который увидят другие:
держите в переменной окружения. Утёк — `/token @имя_bot` выдаст новый.

## Быстрый старт

Библиотеки есть для Node.js и Python; на любом другом языке бот работает прямыми
HTTP-запросами. Бот ниже отвечает `pong` на `/ping`, бросает кубик на `/roll 20` и
повторяет то, что ему пишут в личку.

### Node.js

Node.js 22 или новее, без зависимостей:

```
npm install efir-bot
```

`bot.mjs`:

```js
import { Bot } from "efir-bot";

const bot = new Bot({
  token: process.env.EFIR_TOKEN,
  url: "http://<сервер>:4318",
});

bot.command("ping", (msg) => msg.reply("pong"));

bot.command("roll", (msg, args) => {
  const max = Number(args[0]) || 100;
  return msg.reply(`Выпало ${1 + Math.floor(Math.random() * max)}`);
});

bot.on("message", async (msg) => {
  if (msg.dm && !msg.text.startsWith("/")) await msg.send(`Вы написали: ${msg.text}`);
});

const me = await bot.start();
console.log(`Бот @${me.username} в сети`);
```

```
EFIR_TOKEN=<токен> node bot.mjs
```

Справочник — [библиотека для Node.js](library.md).

### Python

Python 3.10 или новее:

```
pip install efir-bot
```

`bot.py`:

```python
import os
import random

from efir_bot import Bot

bot = Bot(os.environ["EFIR_TOKEN"], "http://<сервер>:4318")


@bot.command("ping")
async def ping(msg):
    await msg.reply("pong")


@bot.command("roll")
async def roll(msg, args):
    top = int(args[0]) if args and args[0].isdigit() else 100
    await msg.reply(f"Выпало {random.randint(1, top)}")


@bot.on("message")
async def talk(msg):
    if msg.dm and not msg.text.startswith("/"):
        await msg.send(f"Вы написали: {msg.text}")


bot.run()
```

```
EFIR_TOKEN=<токен> python bot.py
```

Справочник — [библиотека для Python](python.md).

### Любой другой язык

Всё, что умеет бот, — обычные HTTP-запросы с заголовком `Authorization: Bot <токен>`.
Проверить токен и отправить сообщение можно прямо из консоли:

```
curl -H "Authorization: Bot $EFIR_TOKEN" http://<сервер>:4318/api/v1/users/@me

curl -X POST http://<сервер>:4318/api/v1/channels/$CHANNEL/messages \
  -H "Authorization: Bot $EFIR_TOKEN" -H "Content-Type: application/json" \
  -d '{"text":"Привет"}'
```

Новые сообщения и остальные события приходят по WebSocket — [шлюз событий](gateway.md),
там же пример бота без библиотеки. Все запросы — в [HTTP API](rest.md).

Чтобы бот появился на сервере, дайте ему приглашение:

```js
await bot.servers.join("Kx7pQ2aB"); // Python: await bot.servers.join("Kx7pQ2aB")
```

Дальше участники сервера выдают боту роли, как человеку. Всё, что он может, решают права
этих ролей и особые права каналов.

## Как это устроено

- **HTTP API** — всё, что бот делает: пишет, отвечает, модерирует. Адреса начинаются с
  `/api/v1`, авторизация — заголовок `Authorization: Bot <токен>`.
- **Шлюз событий** — WebSocket, по которому бот узнаёт, что происходит: новые сообщения,
  участники, реакции, голос. Библиотека держит его сама и переподключается при обрывах.

Бот видит только серверы, на которых состоит, и личные чаты, куда ему написали. Первым
написать человеку бот не может, как и в Telegram.

## Лимиты

- 50 запросов в секунду на бота;
- 5 сообщений за 5 секунд в один канал;
- медленный режим канала действует и на ботов, кроме тех, у кого есть право
  «Управлять сообщениями» или «Управлять каналами».

Превышение — ответ `429` с полем `retry_after` (секунды) и заголовком `Retry-After`.
Библиотека ждёт и повторяет запрос сама.

## Ошибки

Любая ошибка — HTTP-статус и `{ "error": "текст" }`. Текст понятен человеку, его можно
показать как есть.

| Статус | Когда |
| --- | --- |
| `400` | неверные данные: пустой текст, слишком длинное имя и т. п. |
| `401` | токен неверный или сброшен |
| `403` | не хватает прав, бот не на сервере, личка закрыта блокировкой |
| `404` | нет такого сообщения, канала, сервера |
| `413` | файл слишком большой (до 1 ГБ, картинки до 20 МБ) |
| `429` | лимит, см. выше |
| `507` | на сервере кончилось место для файлов |

Примеры — [на GitHub](https://github.com/RedArtem39/efir-releases/tree/main/docs/examples) и в самих пакетах (папка `examples`): пинг, кубик, модерация, опрос по расписанию. Что можно и чего нельзя — в [правилах](https://github.com/RedArtem39/efir-releases/blob/main/docs/rules.md).
