# История изменений API

Версия API — `v1`, адреса `/api/v1/…`. Внутри версии поля и события только добавляются:
существующие не меняют смысл и не пропадают. Если что-то придётся убрать или изменить,
это появится здесь заранее и в новой версии адресов.

## 2026-09-26

- Библиотека `efir-bot` для Python (`pip install efir-bot`); библиотека для Node.js — в npm
  (`npm install efir-bot`).
- Вложения: `spoiler=1` при загрузке отправляет картинку или видео под спойлером; у таких
  вложений поле `spoiler: true`.

## 2026-09-25

- Опросы и события: `POST /channels/{id}/polls`, `PUT /polls/{id}/votes`,
  `POST /polls/{id}/close`, `POST /channels/{id}/events`, `PUT /events/{id}/rsvp`;
  права «Создавать опросы» (`1 << 30`) и «Создавать события» (`1 << 29`); событие шлюза
  `EVENT_REMINDER`.
- Пересылка: `POST /messages/{mid}/forward`, поле `forward` у сообщения.
- Голосовые сообщения и кружочки: `variant`, `duration`, `waveform` у вложений.
- Библиотека `efir-bot` для Node.js.

## 2026-09-24 — первая версия

HTTP API `/api/v1`, шлюз событий, создание ботов через `@bot_bot`.
