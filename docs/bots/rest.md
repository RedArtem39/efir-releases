# HTTP API

Всё, что умеет бот, — обычные HTTP-запросы. Их можно проверить прямо из консоли через
curl, а писать бота — на любом языке. На Node.js и Python проще взять библиотеку:
[для Node.js](library.md), [для Python](python.md).

## Основы

| | |
| --- | --- |
| Адрес | `http://<сервер>:4318/api/v1/…` |
| Авторизация | заголовок `Authorization: Bot <токен>` |
| Тело запроса | JSON с `Content-Type: application/json`, до 24 000 байт; у загрузки файлов — сам файл |
| Ответ | JSON; при ошибке — HTTP-статус и `{ "error": "текст" }` |
| Время | миллисекунды с 1970 года, как `Date.now()` |
| id | строки |
| Версия | `v1`; что менялось — в [истории изменений](changelog.md) |

```
curl -H "Authorization: Bot $EFIR_TOKEN" http://<сервер>:4318/api/v1/users/@me
```

Как читать разделы ниже:

- **Право** — какое [право](objects.md#права) нужно боту на сервере или в канале.
  «—» — не нужно ничего, кроме доступа к серверу или каналу.
- В таблицах параметров «да» в столбце «Обяз.» — обязательный параметр, остальные можно
  не передавать.
- «Обрезается до N» — длиннее сервер молча обрежет; «от 1 до N» — длиннее или пустое
  вернёт `400`.
- **Ошибки** — ответы этого запроса сверх общих (`401` при неверном токене, `429` при
  лимите). Все тексты ошибок с причинами — в [каталоге ошибок](errors.md).

### Лимиты

| Что | Сколько | Ключ |
| --- | --- | --- |
| запросы бота | 50 в секунду | весь бот |
| сообщения | 5 за 5 секунд | бот и канал |
| пересылка | 20 за 10 секунд | бот |
| медленный режим канала | 1 сообщение за `slowmode` секунд | бот и канал; не действует при праве «Управлять сообщениями» или «Управлять каналами» |

Превышение — `429` с полем `retry_after` (секунды) и заголовком `Retry-After`. Подождите
столько и повторите запрос. Библиотеки делают это сами.

## Профиль бота

### `GET /users/@me`

Профиль бота. Ответ — [пользователь](objects.md#пользователь).

### `PATCH /users/@me`

Изменить профиль. Ответ — пользователь.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `name` | строка | | отображаемое имя, от 1 до 32 символов |
| `bio` | строка | | «Обо мне», до 190 символов |
| `username` | строка | | новый юзернейм: 5–32 символа, латиница, цифры и `_`, с буквы, на `_bot` |

Ошибки: `400` — длина или формат, `409` — юзернейм занят.

### `PUT /users/@me/avatar`

Тело — сам файл: png, jpg, gif, webp, avif или видео mp4, mov; до 8 МБ. Необязательный
заголовок `X-Avatar-Crop: {"x":0,"y":0,"s":1}` (в URL-кодировке) — квадрат, который виден:
левый верхний угол и сторона в долях картинки, от 0 до 1. Ответ — пользователь.

Ошибки: `400` — пустой файл или неверная обрезка, `413` — больше 8 МБ, `415` — формат.

### `DELETE /users/@me/avatar`

Убрать аватар. Ответ — пользователь.

### `GET /users/{id}`

Профиль пользователя, с которым у бота есть общий сервер, и эти серверы в `spaces`.

Ошибки: `404` — нет пользователя или общих серверов.

## Серверы

### `GET /servers`

Все серверы бота, каждый — [сервер](objects.md#сервер) целиком: каналы, роли, участники,
кто в голосовых.

### `GET /servers/{id}`

Один сервер. Ошибки: `404` — нет такого сервера, `403` — бот не участник.

### `PATCH /servers/{id}`

Право: управлять сервером. Ответ — сервер.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `name` | строка | | от 1 до 40 символов |
| `description` | строка | | обрезается до 300 символов |
| `public` | логическое | | виден в поиске серверов, вступить можно без приглашения |

### `POST /join`

Вступить по приглашению. Ответ — `{ "id": "<id сервера>" }`.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `code` | строка | да | код приглашения или ссылка с ним, до 100 символов |

Ошибки: `404` — приглашение недействительно или истекло, `403` — бот забанен на сервере.

### `POST /servers/{id}/leave`

Покинуть сервер. Тело — `{}`. Ответ — `{ "ok": true }`.

### `GET /servers/{id}/audit-log`

Право: просматривать журнал аудита. Ответ — [записи журнала](objects.md#журнал-аудита),
новые первыми.

| Параметр строки | Тип | Описание |
| --- | --- | --- |
| `before` | число | только записи раньше этого времени |
| `limit` | число | 1–100, по умолчанию 50 |

### `GET /invites/{code}`

Что за приглашение, не вступая: `{ code, server: { id, name, members, verified } }`.
Ошибки: `404`.

## Каналы

### `GET /channels/{id}`

[Канал](objects.md#канал) и итоговые права бота в нём (`permissions`).

### `POST /servers/{id}/channels`

Право: управлять каналами. Ответ — канал. На сервере — до 500 каналов.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `name` | строка | да | от 1 до 32 символов; у текстовых — в нижнем регистре, пробелы → `-` |
| `kind` | строка | да | `text`, `voice` или `category` |
| `parent_id` | строка | | id категории |
| `topic` | строка | | тема текстового канала, обрезается до 1024 символов |

Ошибки: `400` — название, неизвестная категория, 500 каналов уже есть.

### `PATCH /channels/{id}`

Право: управлять каналами. Ответ — канал. Передавайте только то, что меняете.

| Поле | Тип | Описание |
| --- | --- | --- |
| `name` | строка | от 1 до 32 символов |
| `topic` | строка | только у текстовых; обрезается до 1024 |
| `slowmode` | число | секунды между сообщениями одного участника, 0–21600 (6 часов) |
| `parent_id` | строка \| null | категория; `null` — без категории |
| `synced` | логическое | `true` — взять права категории |
| `bitrate` | число | кбит/с, 8–96; только у голосовых |
| `user_limit` | число | 0–25, 0 — без ограничения (не больше 25); только у голосовых |

Числа вне диапазона приводятся к ближайшей границе.

### `DELETE /channels/{id}`

Право: управлять каналами. Ответ — `{ "ok": true }`. Каналы удалённой категории остаются
без категории.

### `PATCH /servers/{id}/channels`

Порядок и категории нескольких каналов сразу. Право: управлять каналами. Ответ — все
каналы сервера.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `channels` | массив | да | `[{ id, position, parent_id }]` |

Ошибки: `400` — не список, неизвестный канал, неверная категория.

### `PUT /channels/{id}/permissions/{target}`

Особые права для роли или участника. Право: управлять ролями; давать и запрещать можно
только те права, что есть у самого бота. Ответ — канал.

`target` — id роли (у `@everyone` он равен id сервера) или id участника.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `type` | строка | да | `role` или `member` |
| `allow` | число | | разрешённые биты прав |
| `deny` | число | | запрещённые биты прав |

Ошибки: `404` — нет канала, роли или участника; `403` — права, которых нет у бота.

### `DELETE /channels/{id}/permissions/{target}`

Убрать особые права. Право: управлять ролями. Ответ — канал.

### `POST /channels/{id}/typing`

«Печатает…» на 10 секунд. Право: отправлять сообщения. Тело — `{}`.

### `GET /channels/{id}/pins`

Закреплённые сообщения, новые первыми. Право: читать историю.

## Сообщения

### `GET /channels/{id}/messages`

[Сообщения](objects.md#сообщение) канала, новые в конце. Право: читать историю.

| Параметр строки | Тип | Описание |
| --- | --- | --- |
| `before` | число | только сообщения раньше этого времени — для листания назад |
| `limit` | число | 1–100, по умолчанию 100 |

```
curl -H "Authorization: Bot $EFIR_TOKEN" \
  "http://<сервер>:4318/api/v1/channels/$CHANNEL/messages?limit=20"
```

### `GET /channels/{id}/messages/{mid}`

Одно сообщение. Ошибки: `404`.

### `POST /channels/{id}/messages`

Отправить сообщение. Право: отправлять сообщения (в личке — не нужно). Ответ — сообщение,
`201`.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `text` | строка | да, если нет вложений | от 1 до 4000 символов; [разметка](#разметка) |
| `attachments` | массив строк | | id [загруженных](#файлы) файлов, до 10; остальные отбрасываются |
| `reply_to` | строка | | id сообщения из этого же канала: ответ с цитатой |

```
curl -X POST http://<сервер>:4318/api/v1/channels/$CHANNEL/messages \
  -H "Authorization: Bot $EFIR_TOKEN" -H "Content-Type: application/json" \
  -d '{"text":"**pong**"}'
```

Ошибки:

- `403` — нет права писать или прикреплять файлы; в личке — человек заблокировал бота
  или ограничил, кто может ему писать;
- `400` — пустой или слишком длинный текст, чужое вложение, сообщение для ответа не найдено;
- `429` — лимит сообщений или медленный режим.

Бот не может написать человеку первым: личный чат появляется, когда человек пишет боту.

### `PATCH /messages/{mid}`

Изменить своё сообщение. Ответ — сообщение.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `text` | строка | да | от 1 до 4000 символов |

Ошибки: `403` — сообщение не бота, `404`.

### `DELETE /messages/{mid}`

Удалить сообщение: своё — всегда, чужое — с правом «Управлять сообщениями». Ответ —
`{ "ok": true }`.

### `PUT /messages/{mid}/reactions/{emoji}`

Поставить реакцию. Право: добавлять реакции. Ответ — реакции сообщения.
`emoji` — один эмодзи в URL-кодировке: 👍 → `%F0%9F%91%8D`.

Ошибки: `400` — не эмодзи или несколько, `403`, `404`.

### `DELETE /messages/{mid}/reactions/{emoji}`

Убрать свою реакцию. Ответ — реакции сообщения.

### `PUT /channels/{id}/pins/{mid}` и `DELETE /channels/{id}/pins/{mid}`

Закрепить или открепить. Право: управлять сообщениями. В канале — до 50 закрепов.
Ответ — `{ "ok": true }`. Ошибки: `400` — уже 50, `403`, `404`.

### `POST /messages/{mid}/forward`

Переслать сообщение с вложениями. Ответ — `{ "ids": [...] }`, id копий по порядку чатов.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `channel_ids` | массив строк | да | от 1 до 10 чатов, куда бот может писать |
| `comment` | строка | | уходит отдельным сообщением перед копией; обрезается до 4000 |

Ошибки: `400` — не 1–10 чатов, пересылка в голосовой канал или категорию; `403` — нет
права писать или прикреплять файлы; `404`; `429` — лимит пересылок.

### Разметка

Как в Discord: `**жирный**`, `*курсив*`, `__подчёркнутый__`, `~~зачёркнутый~~`,
`||спойлер||`, `` `код` ``, блок кода между строками ```` ``` ````, цитата — строка с `> `.
Упоминание — `@username`. Для первых трёх ссылок в тексте сервер через пару секунд
добавит превью (`embeds`) и пришлёт `MESSAGE_UPDATE`.

## Файлы

Сначала файл загружается, потом его id уходит в `attachments` сообщения.

### `PUT /channels/{id}/attachments`

Тело — сам файл, `Content-Type` любой. Право: прикреплять файлы. Ответ —
`{ id, name, kind, size }`, `201`.

| Параметр строки | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `name` | строка | | имя файла; обрезается до 120 символов, `/`, `\` и управляющие символы заменяются на `_` |
| `w`, `h` | числа | | ширина и высота картинки или видео: приложение сразу оставит под них место |
| `spoiler` | `1` | | картинка или видео под спойлером: размыты, пока их не откроют |

- До 1 ГБ; картинки до 20 МБ.
- Тип (`kind`) сервер определяет по содержимому: `image` — png, jpg, gif, webp, avif;
  `video` — mp4, mov, webm; остальное — `file`.
- Файл, который за сутки не попал в сообщение, удаляется.
- Файлы, которые никто не открывал 30 дней, удаляются; у сообщения остаётся вложение с
  `expired: true`.

Ошибки: `400` — пустой файл, `403`, `413` — больше лимита, `507` — хранилище сервера
заполнено или на диске кончается место.

```
curl -X PUT "http://<сервер>:4318/api/v1/channels/$CHANNEL/attachments?name=report.pdf" \
  -H "Authorization: Bot $EFIR_TOKEN" --data-binary @report.pdf
# {"id":"…","name":"report.pdf","kind":"file","size":48213}

curl -X POST http://<сервер>:4318/api/v1/channels/$CHANNEL/messages \
  -H "Authorization: Bot $EFIR_TOKEN" -H "Content-Type: application/json" \
  -d '{"text":"Отчёт","attachments":["<id из ответа выше>"]}'
```

### `GET /attachments/{id}`

Содержимое файла; поддерживает `Range`. Право: читать историю в канале файла.
Ошибки: `404` — нет файла или он удалён, `403`, `416` — неверный `Range`.

## Роли

Бот не может трогать роли не ниже своей высшей и выдавать права, которых нет у него
самого, — как человек.

### `GET /servers/{id}/roles`

Роли сервера, от высшей к `@everyone`.

### `POST /servers/{id}/roles`

Право: управлять ролями. Новая роль встаёт внизу, над `@everyone`. На сервере — до 250
ролей. Ответ — [роль](objects.md#роль).

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `name` | строка | да | от 1 до 32 символов |
| `color` | строка \| null | | `#rrggbb`; другое — без цвета |
| `hoist` | логическое | | показывать отдельной группой в списке участников |
| `permissions` | число | | [биты прав](objects.md#права) |

### `PATCH /servers/{id}/roles/{rid}`

Те же поля, все необязательные. У `@everyone` меняются только `permissions`. Ответ — роль.
Ошибки: `403` — роль не ниже высшей роли бота или права, которых нет у бота; `404`.

### `PATCH /servers/{id}/roles`

Порядок ролей. Тело — `{ "roles": [{ "id", "position" }] }`; чем больше `position`, тем
выше. Ошибки: `400` — не список, неизвестная роль, неверная позиция.

### `DELETE /servers/{id}/roles/{rid}`

Право: управлять ролями. `@everyone` удалить нельзя.

## Участники

### `PUT` и `DELETE /servers/{id}/members/{uid}/roles/{rid}`

Выдать или снять роль. Право: управлять ролями. Ответ — `{ "roles": [...] }`, роли
участника. Ошибки: `403` — роль или участник не ниже бота, `404`.

### `DELETE /servers/{id}/members/{uid}`

Выгнать. Право: выгонять участников. Тело — `{ "reason": "…" }` (необязательно,
обрезается до 512, попадает в журнал аудита). Ошибки: `403` — владелец или участник не
ниже бота, `404`.

### `PATCH /servers/{id}/members/{uid}/voice`

Модерация голоса. Ответ — голосовое состояние участника или `{ "ok": true }`, если он
сейчас не в голосовом (мьют и заглушение сработают, когда он зайдёт).

| Поле | Тип | Право | Описание |
| --- | --- | --- | --- |
| `mute` | логическое | отключать микрофон участникам | серверный мьют; сохраняется между заходами |
| `deaf` | логическое | отключать звук участникам | серверное заглушение; сохраняется между заходами |
| `channel_id` | строка \| null | перемещать участников | в другой голосовой канал; `null` — отключить |

Ошибки: `400` — перемещение участника, который не в голосовом канале этого сервера;
`403` — нет права, роль участника не ниже или у него нет доступа к каналу; `404`.

## Баны

Право: банить участников.

### `GET /servers/{id}/bans`

`[{ user_id, user, reason, actor_id, created }]`, новые первыми.

### `PUT /servers/{id}/bans/{uid}`

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `reason` | строка | | обрезается до 512 |
| `delete_message_seconds` | число | | удалить сообщения участника за последние N секунд, 0–604800 (7 дней) |

Забанить можно и того, кто не на сервере. Ошибки: `400` — сам бот, `403` — владелец или
участник не ниже бота, `404`.

### `DELETE /servers/{id}/bans/{uid}`

Разбанить.

## Приглашения

### `GET /servers/{id}/invites`

Действующие приглашения. Право: управлять сервером.

### `POST /servers/{id}/invites`

Право: создавать приглашения. Ответ — `{ code, space_id, creator_id, created, expires,
max_uses, uses }`, `201`; `expires` — время в мс или `null`, `max_uses` — число или `null`.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `max_age` | число | | секунды жизни, 0–2592000 (30 дней); 0 — бессрочно; по умолчанию 604800 (7 дней) |
| `max_uses` | число | | 0–1000; 0 — без ограничения |

### `DELETE /invites/{code}`

Удалить: своё — всегда, чужое — с правом «Управлять сервером».

## Опросы

Только в текстовых каналах серверов. Сообщение с опросом приходит как обычное, с полем
`poll`.

### `POST /channels/{id}/polls`

Право: создавать опросы. Ответ — `{ id, message_id }`.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `question` | строка | да | от 1 до 300 символов |
| `options` | массив строк | да | 2–10 вариантов, каждый обрезается до 100, без повторов |
| `multiple` | логическое | | можно выбрать несколько вариантов |

### `PUT /polls/{id}/votes`

Проголосовать. Тело — `{ "options": [0, 2] }`: индексы вариантов; пустой список отменяет
голос. Ответ — [опрос](objects.md#опрос).

Ошибки: `400` — опрос завершён, неизвестный вариант, несколько вариантов там, где можно
один; `404`.

### `POST /polls/{id}/close`

Завершить. Может автор опроса или участник с правом «Управлять сообщениями». Тело — `{}`.

## События

Только в текстовых каналах серверов. Сообщение с событием приходит с полем `event`; тем,
кто идёт, за 10 минут до начала приходит `EVENT_REMINDER`.

### `POST /channels/{id}/events`

Право: создавать события. Ответ — `{ id, message_id }`.

| Поле | Тип | Обяз. | Описание |
| --- | --- | --- | --- |
| `title` | строка | да | от 1 до 100 символов |
| `starts` | число | да | время начала, мс; не раньше чем минуту назад и не дальше чем через 366 дней |
| `description` | строка | | обрезается до 1000 |
| `voice_channel_id` | строка | | голосовой канал этого же сервера, где соберутся |

### `PUT /events/{id}/rsvp`

Тело — `{ "answer": "going" }`: `going`, `not_going` или `null` (убрать ответ). Ответ —
[событие](objects.md#событие).

## Прочее

### `GET /gateway`

`{ "url": "/api/gateway", "heartbeat_interval": … }` — куда подключаться за
[событиями](gateway.md).

### `GET /cosmetics` и `GET /cosmetics/{id}`

Каталог оформления профилей и один предмет из него (у каждого `assets[]` есть `url`).
`404`, если на сервере каталога нет.

### Голос

Боты пока не подключаются к голосовым каналам, но видят, кто где сидит (`voice_states` у
сервера и событие `VOICE_STATE_UPDATE`), и модерируют голос.
