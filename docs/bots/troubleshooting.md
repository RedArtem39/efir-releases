# Частые проблемы

## Бот не подключается

**`401`, «Неверный токен бота».** Токен с опечаткой или его сбросили командой
`/token @имя_bot` у `@bot_bot`: после сброса старый перестаёт работать сразу. Возьмите
новый. Библиотеки в этом случае останавливаются с `EfirError`, `status` 401, и не
переподключаются.

**Соединение не устанавливается (таймаут, «connection refused»).** Сервер Эфира доступен
только внутри сети Radmin VPN. Машина, где работает бот, должна быть в этой сети. Проверка:

```
curl http://<сервер>:4318/api/v1/gateway
```

Ответ `{"error":"…"}` со статусом 401 — сервер доступен, дело в токене. Таймаут — нет
сети до сервера.

**`403`, «Боты работают только через /api/v1».** Бот обратился к адресу приложения, а не
Bot API. Все адреса бота начинаются с `/api/v1/`.

## Бот молчит

**Бот не видит сообщения в канале.** Нужны права «Просматривать каналы» и «Читать историю»
в этом канале. Проверьте особые права канала: запрет для `@everyone` или для роли бота
перекрывает разрешение на сервере. Итоговые права бота в канале — поле `permissions` в
`GET /channels/{id}`.

**Команды не срабатывают.** Команда — сообщение, которое начинается с префикса (по
умолчанию `/`). `/ping@другой_bot` адресована другому боту, и ваш её пропустит. Свои
сообщения бот не получает вообще.

**Бот не отвечает в личке.** Бот не может написать человеку первым: личный чат появляется,
когда человек пишет боту. Если человек закрыл личку или заблокировал бота, ответ вернёт
`403`.

**Бот отвечает с задержкой или не всё.** Скорее всего, лимит: 5 сообщений за 5 секунд в
один канал и 50 запросов в секунду на бота. Библиотеки ждут и повторяют сами (событие
`rateLimit` / `rate_limit`). В своём коде на HTTP ждите `retry_after` секунд после `429`.

## Не хватает прав

**`403`, «Недостаточно прав», хотя роль с правом выдана.** Проверьте:

1. Право запрещено особыми правами канала.
2. Действие над ролью или участником не ниже высшей роли бота: поднимите роль бота выше.
3. Бот пытается выдать право, которого нет у него самого.

**Нельзя выгнать или забанить владельца** — так задумано.

## Файлы

**`413` при загрузке.** Файлы — до 1 ГБ, картинки — до 20 МБ, аватар — до 8 МБ.

**Файл загружен, но сообщение отвечает «Вложение не найдено».** id вложения работает только
в том канале, куда файл загружали, только для этого бота и только один раз.

**У вложения `expired: true`.** Файл никто не открывал 30 дней, и сервер его удалил.
Вложение без сообщения удаляется через сутки.

## Библиотеки

**Node.js: `Нужен Node.js 22 или новее`.** Библиотеке нужен встроенный `WebSocket` из
Node.js 22+.

**Python: `RuntimeError: no running event loop` или ничего не происходит.** `bot.start()` —
корутина: вызывайте её через `await` внутри `asyncio` или используйте `bot.run()`.

**Исключение в обработчике «пропало».** Библиотеки не роняют бота из-за ошибки в
обработчике: она уходит в событие `error`, а если на него никто не подписан — в консоль
(Node.js) или в логгер `efir_bot` (Python). Подпишитесь на `error`, чтобы видеть их.
